# CraneControl

PlatformIO Arduino project for an Arduino Pro Mini (5V, 16MHz, ATmega328P).

## Build

```
pio run
```

## Upload

```
pio run -t upload
```

## Notes

Arduino Pro Mini boards have no onboard USB; use an FTDI/USB-serial adapter
connected to the DTR pin for upload and reset.
